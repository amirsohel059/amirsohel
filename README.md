# Amir Sohel Sheikh — Portfolio

A responsive, static portfolio focused on embedded software, edge AI, computer vision, and robotics. Content is based on the supplied résumé.

## Preview

Open `index.html` in a browser, or serve this folder locally:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8080`. No build or dependency installation is required. Google Fonts is optional; system fonts provide a fallback.

## Update

- `index.html`: profile, projects, career history, skills, and contact links.
- `style.css`: responsive layout, illustrations, dark/light themes, and reduced-motion support.
- `script.js`: project filters, system explorer, accessible skill tabs, mobile navigation, theme preference, and email copying.
- `images/Resume.pdf`: current downloadable résumé. Replace this file to update both download links.

Project illustrations are conceptual. The translation device and body-worn camera are labeled in development, consistent with the résumé. Contact buttons open the visitor's email or telephone application; no contact-form backend is required.

The existing repository can be served by any static hosting provider. Changes here do not publish or deploy the website automatically unless the repository already has deployment automation configured.
